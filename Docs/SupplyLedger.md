# Hold supply ledger

A physical ledger now sits inside the storage hold. Walk down both stair flights, look at it, and press **E** to inspect the ship's current planks, powder charges, cannonballs and food rations. These values come from the same inventory that cannon loading and hull repairs consume.

The blockout currently presents the ledger values as a compact overlay after interaction. A modeled book, page animation and visible cargo updates are still future art and UI work.
