# Shared crew work simulation

A role-aware job board creates one job per cannon reload, hull breach, or bilge pump need. Two simulated gunners and a carpenter claim available jobs by priority and distance. A gunner advances a cannon's physical loading stages over time; the carpenter patches breaches before pumping remaining water. The crew pauses a cannon job while the captain operates that cannon, so player and crew cannot reload it simultaneously.

The passive target ship has no working crew, so cannon impacts can be observed without automatic repair. This is a low-frequency simulation foundation. It is not yet visible crew AI: characters, movement on the ship, animation, conversations, morale, and the command radial interface still need implementation and Unreal runtime testing.
